# KHWARIZMAX
## Advanced Scientific Calculator & Mathematical Toolkit

**KHWARIZMAX** is an advanced desktop scientific calculator developed using Python. It combines a professional dark-mode interface with a comprehensive collection of mathematical and scientific tools.

Designed to support students and users who need more than basic calculations, KHWARIZMAX brings multiple mathematical features together in one application.

## Main Features

### 1. Scientific Calculator
- Basic arithmetic operations.
- Trigonometric functions: sin, cos, tan.
- Inverse trigonometric functions: asin, acos, atan.
- Hyperbolic functions: sinh, cosh, tanh.
- Inverse hyperbolic functions.
- Square roots and cube roots.
- Powers and exponential functions.
- Logarithms: log and ln.
- Factorials.
- Absolute values, rounding, floor and ceiling.
- DEG / RAD / GRAD angle modes.
- Mathematical constants: π, e and τ.

### 2. Advanced Mathematical Tools
- Memory management: MC, MR, M+, M- and MS.
- Persistent calculation history.
- Reuse and delete individual calculations.
- Clear calculation history with confirmation.
- Previous answer support (Ans).

### 3. Scientific Constants
A collection of mathematical and physical constants, including:
- Speed of light.
- Gravitational acceleration.
- Planck constant.
- Avogadro constant.
- Electron charge.
- Gas constant.
- Boltzmann constant.
- Golden ratio.

### 4. Unit Conversions
Convert between different units of:
- Length.
- Mass.
- Volume.
- Area.
- Time.
- Speed.
- Temperature.
- Currency using a manually entered exchange rate.

### 5. Matrix Operations
Tools for working with 2×2 matrices:
- Matrix addition.
- Matrix multiplication.
- Determinant calculation.
- Matrix inverse.

### 6. Mathematical Graphing
- Plot mathematical functions.
- Plot multiple functions simultaneously.
- Adjustable X-axis range.
- Zoom in and zoom out.
- Pan around the graph.
- Automatic Y-axis fitting.
- Interactive point inspection.
- Approximate slope calculation.
- Function value tables.
- Ready-to-use function examples.

### 7. Mathematical Laws & Formulas
A reference library containing:
- Algebraic identities.
- Plane geometry formulas.
- Three-dimensional geometry formulas.
- Trigonometric identities and laws.
- Exponents and logarithms.
- Physics and motion formulas.
- Statistics.
- Basic unit relationships.

### 8. Interactive Geometry
Explore geometric shapes with visual illustrations, formulas and worked examples.

Available shapes include:
- Square.
- Rectangle.
- Triangle.
- Circle.
- Parallelogram.
- Trapezoid.
- Rhombus.
- Cube.
- Rectangular prism.
- Cylinder.
- Sphere.
- Cone.

### 9. Help, About & Settings
- Built-in help section explaining how to use the calculator.
- About KHWARIZMAX section with application information.
- Settings for calculator preferences.
- Angle mode configuration.

## Interface & Experience
- Professional modern dark-mode design.
- Image-based interface with transparent interactive controls.
- Smooth button interactions.
- Organized mathematical sections.
- Designed for a practical desktop experience.

## Technology
- Programming language: Python.
- GUI framework: Tkinter.
- Image processing: Pillow.
- Desktop platform: Windows.

# خواريزماكس | KHWARIZMAX
## حاسبة علمية متقدمة ومجموعة أدوات رياضية

**خواريزماكس** هو تطبيق حاسبة علمية متقدم للحاسوب، تم تطويره باستخدام لغة Python. يجمع بين واجهة احترافية بتصميم داكن ومجموعة متنوعة من الأدوات الرياضية والعلمية في تطبيق واحد.

صُمّم التطبيق ليقدم أكثر من مجرد العمليات الحسابية الأساسية، ويوفر أدوات تساعد الطلاب والمستخدمين في الحسابات والدراسة والاستكشاف الرياضي.

## المميزات الرئيسية

### 1. الحاسبة العلمية
- العمليات الحسابية الأساسية.
- الدوال المثلثية: sin وcos وtan.
- الدوال المثلثية العكسية.
- الدوال الزائدية والعكسية.
- الجذر التربيعي والجذر التكعيبي.
- الأسس والقوى والدوال الأسية.
- اللوغاريتمات: log وln.
- المضروب (Factorial).
- القيمة المطلقة والتقريب والأرضية والسقف.
- أوضاع الزوايا DEG / RAD / GRAD.
- الثوابت الرياضية π وe وτ.

### 2. الأدوات الحسابية المتقدمة
- إدارة الذاكرة: MC وMR وM+ وM- وMS.
- سجل العمليات مع الاحتفاظ بالنتائج.
- إعادة استخدام العمليات السابقة.
- حذف عملية واحدة أو حذف السجل كاملاً بعد التأكيد.
- استخدام النتيجة السابقة Ans.

### 3. الثوابت العلمية
مجموعة من الثوابت الرياضية والفيزيائية، منها:
- سرعة الضوء.
- تسارع الجاذبية.
- ثابت بلانك.
- عدد أفوغادرو.
- شحنة الإلكترون.
- ثابت الغاز.
- ثابت بولتزمان.
- النسبة الذهبية.

### 4. تحويل الوحدات
- تحويل وحدات الطول.
- تحويل الكتلة.
- تحويل السعة.
- تحويل المساحة.
- تحويل الزمن.
- تحويل السرعة.
- تحويل درجات الحرارة.
- تحويل العملات باستعمال سعر صرف يدوي.

### 5. عمليات المصفوفات
أدوات للتعامل مع المصفوفات من الرتبة 2×2:
- جمع المصفوفات.
- ضرب المصفوفات.
- حساب المحدد.
- حساب معكوس المصفوفة.

### 6. الرسم البياني للدوال
- رسم الدوال الرياضية.
- رسم عدة دوال في الوقت نفسه.
- تحديد مجال X.
- التكبير والتصغير.
- تحريك الرسم البياني.
- الملاءمة التلقائية لمحور Y.
- استكشاف نقاط المنحنى.
- حساب الميل التقريبي.
- إنشاء جدول قيم الدوال.
- أمثلة جاهزة للدوال الرياضية.

### 7. القوانين والصيغ الرياضية
مكتبة مرجعية تضم:
- المتطابقات الجبرية.
- قوانين الهندسة المستوية.
- قوانين الهندسة ثلاثية الأبعاد.
- المتطابقات والقوانين المثلثية.
- قوانين الأسس واللوغاريتمات.
- قوانين الفيزياء والحركة.
- الإحصاء.
- علاقات تحويل الوحدات الأساسية.

### 8. الأشكال الهندسية التفاعلية
استكشاف الأشكال الهندسية من خلال رسومات توضيحية، مع عرض القوانين والأمثلة المحلولة لكل شكل.

الأشكال المتوفرة:
- المربع.
- المستطيل.
- المثلث.
- الدائرة.
- متوازي الأضلاع.
- شبه المنحرف.
- المعين.
- المكعب.
- متوازي المستطيلات.
- الأسطوانة.
- الكرة.
- المخروط.

### 9. المساعدة وحول التطبيق والإعدادات
- قسم المساعدة لشرح كيفية استخدام الحاسبة وأدواتها.
- قسم حول خواريزماكس للتعريف بالتطبيق ومعلوماته.
- إعدادات لتخصيص بعض تفضيلات الحاسبة.
- ضبط وحدة قياس الزوايا.

## الواجهة وتجربة الاستخدام
- تصميم احترافي عصري بتصميم داكن (Dark Mode).
- واجهة تعتمد على الصور ومناطق ضغط تفاعلية شفافة.
- تأثيرات سلسة عند الضغط على الأزرار.
- تنظيم الأدوات في أقسام واضحة.
- تجربة استخدام موجهة للحاسوب.
